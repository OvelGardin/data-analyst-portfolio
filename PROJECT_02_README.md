# Project 02 — Lending Operations Analysis

## Objective
Analyze a simulated consumer-lending application dataset to understand approval patterns and operational processing time.

## Tools
- SQL
- Excel
- Business analysis

## Dataset
Synthetic lending application data created specifically for portfolio practice. It is not GoTo/GoPay data and does not represent real customer information.

## Key Questions
1. What is the overall approval rate?
2. Which acquisition channel has the strongest approval rate?
3. How does approval rate vary by credit-score band?
4. How long does application processing take?

## Deliverables
- `project_02_lending_applications.csv`
- `project_02_lending_operations.sql`

## Why this project is relevant
The project mirrors common Business Intelligence tasks in lending operations: monitoring application volume, approval performance, and operational turnaround time.
