# Lending Operations Dashboard

## Project Overview

Operational teams need a clear view of application volume, approval performance, and processing efficiency to monitor day-to-day lending operations.

This project presents an interactive-style Excel dashboard built from simulated lending application data.

> **Note:** This project uses 100% synthetic data created for portfolio purposes. It is not real GoTo or GoPay data.

---

## Objectives

The dashboard was designed to help operational teams:

1. Monitor total lending applications.
2. Track overall approval rate.
3. Monitor average application processing time.
4. Compare performance across acquisition channels.
5. Identify operational trends over time.

## Dashboard KPIs

The dashboard includes the following key performance indicators:

| KPI | Purpose |
|---|---|
| Total Applications | Monitor application volume |
| Approval Rate | Track application approval performance |
| Average Processing Hours | Monitor operational efficiency |
| Average Requested Amount | Understand average loan demand |

---

## Dashboard Analysis

### Monthly Application Volume

Monthly application volume is visualized to identify changes in demand and potential seasonal patterns.

### Approval Rate by Channel

Application channels are compared to identify differences in approval performance.

### Processing Performance

Average processing time is monitored to help identify potential operational bottlenecks.

---

## Business Insights

- The dashboard summarizes **1,000 simulated lending applications** with an overall approval rate of **54.90%**.
- Average application processing time was approximately **15.72 hours**, providing a baseline for monitoring operational turnaround time.
- The **Partner** channel recorded the highest approval rate at **58.28%**, followed by Mobile App at **55.16%** and Web at **51.52%**.
- Approved applications required an average of **17.63 hours** to process, compared with **13.39 hours** for rejected applications.
- The dashboard allows lending operations teams to monitor application volume, approval performance, processing efficiency, and channel-level performance in one view.
---

## Business Recommendations

Based on the dashboard, lending operations teams could:

1. Monitor **approval rate and processing time together** to identify potential operational bottlenecks.
2. Compare channel performance regularly to understand differences in application quality and operational efficiency.
3. Review processing steps for approved applications, which currently require more processing time than rejected applications.
4. Use the dashboard as a recurring operational monitoring tool to track changes in application volume and lending KPIs over time.
