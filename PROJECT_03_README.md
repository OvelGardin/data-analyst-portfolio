# Lending Operations Dashboard

## Project Overview

Operational teams need a clear view of application volume, approval performance, and processing efficiency to monitor day-to-day lending operations.

This project presents an interactive-style Excel dashboard built from simulated lending application data.

> **Note:** This project uses 100% synthetic data created for portfolio purposes. It is not real GoTo or GoPay data.

---

## Objectives

The dashboard was designed to help operational teams:

1. Monitor total lending applications.
2. Track overall approval rate.
3. Monitor average application processing time.
4. Compare performance across acquisition channels.
5. Identify operational trends over time.

## Dashboard KPIs

The dashboard includes the following key performance indicators:

| KPI | Purpose |
|---|---|
| Total Applications | Monitor application volume |
| Approval Rate | Track application approval performance |
| Average Processing Hours | Monitor operational efficiency |
| Average Requested Amount | Understand average loan demand |

---

## Dashboard Analysis

### Monthly Application Volume

Monthly application volume is visualized to identify changes in demand and potential seasonal patterns.

### Approval Rate by Channel

Application channels are compared to identify differences in approval performance.

### Processing Performance

Average processing time is monitored to help identify potential operational bottlenecks.

---

## Business Insights

The dashboard enables stakeholders to quickly identify:

- Changes in application volume
- Differences in approval performance between channels
- Overall operational processing efficiency
- Potential areas requiring further investigation

---

## Business Recommendations

Based on the dashboard, an operations team could:

1. Monitor application volume regularly to anticipate workload.
2. Investigate channels with lower approval performance.
3. Track processing time to identify potential operational bottlenecks.
4. Use KPI trends to support resource planning.
5. Combine operational and approval metrics when evaluating overall performance.
