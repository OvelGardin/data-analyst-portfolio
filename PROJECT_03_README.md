# Project 03 — Lending Operations Dashboard

## Objective
Create an operational dashboard for a simulated lending business.

## KPIs
- Total applications
- Approval rate
- Average processing time
- Average requested amount
- Monthly application volume
- Approval rate by channel

## Tools
- Excel
- Pivot-style aggregation
- Charts / dashboard design

## File
Open `project_03_lending_operations_dashboard.xlsx`.

## Important note
All data is synthetic and created for portfolio practice. No real customer or company data is used.
