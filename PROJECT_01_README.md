# Project 01 — E-commerce Sales Analysis

## Objective
Analyze sales performance to identify revenue trends, high-performing categories/products, and regional opportunities.

## Tools
- SQL
- Excel / spreadsheet analysis

## Dataset
Synthetic e-commerce transaction data created for portfolio practice. It does not represent real company data.

## Key Questions
1. How does revenue change month to month?
2. Which categories and products contribute the most revenue?
3. Which regions generate the most revenue?
4. Where could the business focus its sales effort?

## Deliverables
- `project_01_sales_data.csv`
- `project_01_ecommerce_sales.sql`

## Portfolio takeaway
This project demonstrates data cleaning, aggregation, KPI analysis, SQL grouping, sorting, and business-oriented insight generation.
